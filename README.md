# Maria Delivery

Repositório criado para fins didáticos, como parte das atividades da Cinética. O objetivo é configurar o ambiente de desenvolvimento e aprender a versionar código com Git e GitHub, ferramentas que serão usadas em todos os projetos da Cinética.

O projeto é o desenvolvimento de uma página web para um delivery de pizzas da cidade de Cachoeiro de Itapemirim chamado Maria Delivery. O objetivo da aplicação é o auxílio no momento do atendimento dos clientes, tal como a padronização e o envio de mensagens automáticas para eles, além de tentar captar uma maior clientela e aumentar a visibilidade desse comércio.

## Tecnologias usadas

- **Git**: controle de versão local.
- **GitHub**: hospedagem do repositório e colaboração.
- **VS Code**: editor de código-fonte.
- **HTML e CSS**: desenvolvimento da página.
- **Live Server** (extensão do VS Code): visualização da página em tempo real.
- **N8N** (automação): verificação do email e envio automático para validação.
